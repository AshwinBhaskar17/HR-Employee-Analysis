Project Overview

This project focuses on analyzing Human Resources (HR) and employee-related data using Microsoft Excel. It provides interactive dashboards to explore workforce information, employee performance, engagement, recruitment, and training activities.
The project uses Excel dashboards, charts, KPIs, and data analysis techniques to transform raw HR data into meaningful insights that can support better HR decision-making.

Project Objectives

Analyze overall workforce and employee distribution.
Monitor active and inactive employee statistics.
Understand employee engagement and satisfaction levels.
Explore recruitment and applicant information.
Evaluate employee training programs and outcomes.
Present key HR metrics through interactive dashboards.

Dataset Details

The workbook contains four datasets:
Employee Data – Employee information, job titles, departments/business units, employment status, and other workforce details.
Engagement Data – Employee engagement, satisfaction, and work-life balance scores.
Recruitment Data – Applicant information and recruitment-related details.
Training Data – Training programs, training types, outcomes, duration, and costs.
